# Dhivehi Poster Studio

i want to make an social media news style poster maker . native for dhivehi but english supported as well. i will send sample ideas how i want posters to be.

get inspired by such Ui and builds and make one, maximum customizations need. install all common dhivehi fonts as well. Include presets inspired directly by the attached sample posters (paper texture editorial quote cards, speaker cutout portraits, speech bubble containers, highlighted keyword accents, speaker name and designation tags, category badges, outlet branding, social handles footer, and high-res export in 1:1, 4:5, and 9:16 aspect ratios). Ensure full RTL Thaana script support, Thaana phonetic keyboard typing toggle, and common Dhivehi fonts (Faruma, MV Waheed, MV Eamaan, A-Kalaa, etc.).
